1. Selesaikan QA alur customer, admin, developer, billing, reseller, dan guest/security pada staging; siapkan undangan uji publik serta kredensial Xendit Test Mode, bucket R2 non-production, dan email uji.

Isolasi network runtime sudah diverifikasi. Fixture staging dan foto WebP sintetis lolos LCP #6; profil `full-load` mencapai 1.000 VU untuk API health dan fixture undangan read-only pada [Staging quality #6](https://github.com/kuloryan1/tamukita/actions/runs/39179709921). Uji upload serta R2 non-production tetap terpisah. Pastikan provider hanya memakai akun/data non-production sebelum transaksi uji dan pilot.
3. Lakukan restore drill dan pemeriksaan monitoring di VPS, selesaikan keputusan operator/legal yang terbuka, lalu jalankan pilot sebelum production.
